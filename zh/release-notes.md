# Cloud Access Release Notes

**Security > Cloud Access > Release Notes**

## November 11, 2025

### Added New Feature

* Added multi-factor authentication registration procedure
    * Added the feature to register TOTP manually.
* Added the first authentication option
    * Added the auto-save account name feature.
* Added the user setting feature
    * Added the feature to set idle time.
* Added the feature to reset passkey
    * Added the feature to reset passkey in Overflow menu.
* Added the feature to change password
    * Added the feature to allow users to change their own passwords.

### Feature Updates

* Improved user policies
    * Improved **[Policy-User Policy]** **[Policy-User Policy]** tab to allow you to edit or delete the default user policy (default-group).
    * Changed the number of IP addresses that can be entered in the accessible range to 100.
    * Updated UIs for convenience.

## July 15, 2025

### Release of a New Cloud Access Service

Cloud Access is a service that supports secure access to NHN Cloud resources based on a Zero Trust security model.
